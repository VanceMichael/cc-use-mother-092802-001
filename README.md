# 央企人工智能资源普惠开放治理

管理人工智能模型、数据和算力资源的申请、评审、配额与公平开放。

## 参与方与事实

主要参与方包括社区运营人员、央企资源提供方、开发者、安全审核人员、行业场景负责人。领域资料记录以下已经确认的事实：

- 人工智能焕新社区2.0汇聚超过3万个模型和4000个数据集
- 社区建设具身智能和人工智能安全等专区
- 平台支撑3万多名开发者开展应用创新

## 业务约束

- 资源与许可版本
- 申请评审
- 算力配额守恒
- 敏感信息裁剪
- 公平性解释

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/ai_resource_context.py` 负责读取和校验这些资料。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

两条命令只读取仓库内文件，不需要连接外部业务系统。
